날짜별 일정

시각은 모두 한국 시간. 여행 기간에는 파란 글씨로 현지 시각을 함께 적었어요. 나 직접 · Claude · 자동 예약·자동 공개

플랫폼별 황금 시간대 (한국 시간)

플랫폼올리는 시각이유주기
유튜브 쇼츠09:00미국 동부 전날 19:00 = 영어 시청자 저녁. 첫 1~2시간 반응으로 피드 시험이 넓어짐하루 1편, 몰아 올리지 않기
네이버 블로그00:00 예약 (또는 07:30)검색 유입이 대부분이라 시각보다 꾸준함이 중요. 깃허브(00:05)보다 먼저 공개해야 중복 문서 위험이 적음2~3일에 1편 (화·목·토)
네이버 클립12:00–13:00 · 19:00–21:00점심·퇴근 뒤 휴대폰 시간블로그와 같은 날 같은 주제
인스타 릴스20:00 (또는 12:00)한국 시청자 저녁. 첫 1시간 공유·저장이 가장 센 신호블로그 날 + 여유 있으면 매일
레딧22:00–01:00미국 동부 아침 8~11시. 새 글이 올라오는 시간에 일찍 단 댓글이 위로 감댓글 하루 2~3개, 자기 링크 금지

일반적인 경향이에요. 2주마다 각 앱의 인사이트(시청자 활동 시간)를 보고 고쳐요.

예약·게시 방법

네이버 블로그 예약 발행 — 직접
  • 깃허브 블로그 글 주소 끝에 #naver → 제목 복사·본문 복사 → 네이버 글쓰기에 붙여넣기
  • 발행 → 발행 시간 예약 → 날짜·시각 (00:00)
  • 공개된 뒤 네이버 글 주소를 Claude에게 → 대시보드 '네이버 게시' 표시
  • Claude는 네이버에 직접 올릴 수 없어요 (크롬 안전 제한, 글쓰기 API 없음)
깃허브 블로그 — 자동
  • 글의 date가 되면 매일 00:05(한국)에 저절로 공개. 할 일 없음
인스타 릴스 예약 — Claude 또는 직접
  • 컴퓨터: Meta Business Suite(business.facebook.com) → 플래너 → 릴스 만들기 → 예약 (Claude가 크롬으로 대신 가능)
  • 휴대폰: 릴스 올리기 → 고급 설정 → 이 릴스 예약
  • 캡션: 첫 줄 질문 + "프로필 링크에서 직접 돌려 보기" + 해시태그 3~5개 (글 속 링크는 눌리지 않음)
네이버 클립 — 직접
  • 파일: 바탕화면 › 업로드-1114-쇼츠11 › 네이버클립-이름 › …가벼운판.mp4
  • 제목·설명·해시태그는 모음 페이지의 복사 버튼, 설명 끝 "블로그에서 👉" 줄에 블로그 글 주소
  • 예약 기능은 앱에서 확인 필요. 없으면 표의 시각에 직접 올리기
유튜브 쇼츠 — 직접
  • YouTube Studio에서 올리고 예약 09:00. 제목·설명·태그·고정 댓글은 업로드 체크리스트
  • 공개 뒤 영상 주소를 Claude에게 → 사이트 실험 페이지에 연결
  • 같은 내용 리마스터를 다시 올릴 때만: 새 영상이 공개된 뒤 옛 영상을 '일부 공개'로

댓글 관리

  • 올린 뒤 첫 1시간: 달린 댓글에 모두 답하기. 이 시간 반응이 노출을 가장 크게 좌우해요
  • 하루 두 번 (한국 점심·밤, 또는 현지 편한 때): 유튜브 → 클립 → 릴스 → 블로그 순서로 훑기
  • 답글은 질문으로 끝내기 ("어느 줄에 서세요?") → 대화가 이어지면 노출이 늘어요
  • 좋은 질문은 고정 댓글·다음 편 글감으로. 메모해서 Claude에게
  • 악플·스팸: 답하지 말고 숨기기/신고. 정치 논쟁은 피하기
  • 블로그: 이웃 블로그 3곳 방문·댓글 (주 2~3회) → 이웃 늘리기
  • 레딧: 남의 글에 도움 되는 댓글만. 링크·홍보는 계정이 쌓인 뒤 소개 글 1번 (귀국 뒤)

전략

  • 한 주제, 같은 날, 세 곳: 블로그(검색) → 클립·릴스(피드) → 사이트(직접 돌려 보기). 서로 링크로 손님을 넘겨줘요
  • 유튜브는 영어, 네이버·인스타는 한국어. 한국어판을 유튜브 같은 채널에 올리지 않기 (반복 콘텐츠로 보임)
  • 제목은 생활 질문: "어느 줄이 빨라?" "왜 두 대씩 와?" — 검색어가 되고 클릭을 받아요
  • 첫 1~2초 큰 질문 문구, 끝 화면은 첫 화면으로 이어지게 (반복 시청)
  • 숫자는 사이트 모델로 실제 돌린 값만. 블로그 예고 숫자 = 다음 편 본문 숫자
  • 몰아 올리지 않기: 하루 1편이 노출을 나눠 먹지 않아요. 쉬는 기간은 예약으로 채우거나 그냥 쉬어도 돼요
  • 2주마다 점검: 조회수·시청 지속·유입 시간대를 보고 시각·주제 조정
여행 중 주의
  • 크루즈·이동 중 와이파이가 느려요 → 큰 영상은 이심 데이터나 리조트 와이파이로
  • 휴대폰에 영상·로그인을 출발 전에 준비 (집 Mac 파일은 밖에서 못 꺼내요)
  • 매일 아침 보고(09:00 한국)는 현지 새벽 2시에 와요
